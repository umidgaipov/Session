# База тестовых заданий по курсу «Экономическая статистика»

Проект содержит 100% покрытие вопросов и расчетных задач из программы курса (на основе [docs/answers_prepared.md](docs/answers_prepared.md)). Все тесты снабжены реалистичным контекстом, 4 вариантами ответа, 1 верным решением и подробным разбором методологических ошибок (дистракторов).

## 1. Теоретические ситуационные тесты (95 вопросов)

* **Источник:** [docs/answers_prepared.md](docs/answers_prepared.md) (Раздел I, вопросы 1–90 и 99–103).
* **Специфика:** Вместо сухого воспроизведения определений каждый вопрос переформулирован в **прикладную ситуацию** (финтех, ритейл, A/B-тестирование, медицина, риск-менеджмент).
* **Структура каждого теста:**
  - `situation` / `scenario` — прикладной контекст;
  - `question` — целевой вопрос;
  - `options` — ровно 4 варианта (A, B, C, D);
  - `correct_option_id` — правильный ответ (сбалансированное распределение по буквам);
  - `distractor_explanations` — анатомия ловушек (почему именно неверны остальные 3 варианта);
  - `explanation` — строгое математическое и социально-экономическое обоснование.

## 2. Практические расчетные тесты (57 задач)

* **Источник:** [docs/answers_prepared.md](docs/answers_prepared.md) (Раздел II. Практика, задачи 1–57).
* **Специфика:** Варианты ответов сформулированы как **готовые методы решения**:
  - **1 верный вариант:** правильная формула, верный выбор критерия/шкалы и точный расчет.
  - **3 дистрактора-ловушки:** типичные экзаменационные ошибки (не тот критерий, ошибка в $df$, забыли корень в $SE$, перевернутый $p$-value, простая средняя вместо взвешенной/геометрической).
  - **Разбор:** пошаговый расчет и объяснение каждой ловушки.

---

## 3. Автоматическая проверка целостности

Для проверки базы тестов запустите встроенный скрипт:

```bash
python validate_tests.py
```

Скрипт проверяет:
1. 100% покрытие вопросов без пропусков (95 из 95).
2. Валидность синтаксиса JSON и Markdown (UTF-8).
3. Инварианты: ровно 4 варианта ответа, ровно 1 верный ключ, отсутствие заглушек (`TODO`, `TBD`).
